Qwen mode runs on your GPU, not a cloud inference service. Simulator mode uses scripted responses, not a model. It needs roughly 7–10 GB of available GPU memory (more context uses more memory). Linux uses an additional 512 MB. Answers can still be wrong—check commands and results.

LOCAL IMAGE GENERATION

Your first PNG

Once Janus is ready, run this in the Linux shell:

term-llm image --generate "A pelican riding a bike." --seed 1 -o pelican.png

Saves pelican.png and its metadata in your workspace and displays the PNG in the terminal.

Use the controls below the terminal to cancel, unload, retry, or reload your selected text provider. Your files and lesson progress stay intact.

Optional image generation · real local Janus · ~3 GB

Separate from the six canned image Easter eggs. No image model or runtime downloads until you enable it. Requires WebGPU and several GB of free GPU memory. Generation is local; prompts are not sent to a server. Downloads come from Hugging Face.

Enabling releases the text worker (including Qwen) before Janus loads. Text requests pause; your Linux files and tutorial progress remain. Cancel / unload releases Janus, not its browser cache. Reload text releases Janus before reloading your chosen text provider. Simulator stays scripted for text; its image generation is real.

Off · no image downloads until you accept and enable.

Return to the shell with /quit, then:

term-llm image --generate "A pelican riding a bike." --seed 1 -o pelican.png

Seed is optional (a random seed is recorded when omitted). Saves PNG + .png.json prompt/seed metadata in your current directory and displays inline in the terminal. Existing term-llm image cat (also dog, elephant, rabbit, fox, owl) remains explicitly canned. Nothing is substituted on failure. Images may be inaccurate or inappropriate; inspect them before sharing. Download files before shutting down.

Type commands in the terminal. Back / Next never run commands or reset your files. In chat, /quit returns to the shell.
